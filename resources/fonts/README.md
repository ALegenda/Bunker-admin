# Шрифты исходных правил

Подключены полные Segoe Print Regular (`segoepr.ttf`) и Bold (`segoeprb.ttf`), версия 5.04;O365. Системные шрифты не устанавливаются и не изменяются; генератор подключает эту папку только для своей сборки. Файлы не раздаются веб-сервером.

Скачаны 16 сентября 2026 года напрямую из Microsoft Font Service. Идентификаторы взяты из локального каталога облачных шрифтов установленного Office, версия 4.42:

- Regular: https://fs.microsoft.com/fs/4.42/rawguids/37891634245
- Bold: https://fs.microsoft.com/fs/4.42/rawguids/31471428232

Проверены таблицы имён и Unicode: по 667 символов, весь русский алфавит, включая Ё/ё. SHA-256:

```
segoepr.ttf  fb4d2c33c6167342177a33a5ca72ffdcaa2a901498bbad942e9802ec2031bc6e
segoeprb.ttf f23e3e1da3e6b0064829268525fc1481bbde02deb43249b4d13c9e01e7c71af7
```

Справка Microsoft: https://support.microsoft.com/en-us/office/cloud-fonts-in-office-f7b009fe-037f-45ed-a556-b5fe6ede6adb

При отсутствии этих файлов экспорт помечается предупреждением о подмене. Наличие правильных шрифтов само по себе не подтверждает точность всей вёрстки: она проверяется отдельно.
