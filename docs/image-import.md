# Изображения карточек

Из исходника «Правила Бункер Картинки.doc» через рабочую копию DOCX извлечены изображения. Оригинал Word не изменён. Содержание PDF и Word не сверялось, тексты JSON не обновлялись.

Подключены 257 из 260 карточек. Совпадения определяются по полному названию и типу карточки, с учётом абзаца, к которому привязано изображение. Это позволяет различать одноимённые умения и мёртвые бонусы. Служебные картинки разделов исключены. Сопоставления просмотрены на контактных листах.

Особые случаи:

- «Левый»: у абзаца в Word нет названия; соответствие подтверждено надписью на изображении.
- «Пойман, не пойман – вор!»: тире входит в название и не должно ошибочно считаться началом описания.
- «Лидер»: картинка заголовка раздела «Умение» не является картинкой этой карточки.

Не найдены подтверждённые изображения для мёртвых бонусов «Вообще не айс», «Нечего скрывать», «Связи в суде». Вместо подстановки одноимённых умений оставлено явное состояние «Изображение не найдено». Фильтр «Без изображения» показывает эти записи.

Файл public/assets/card-images.json содержит путь, название, тип, номера абзацев, исходный медиаресурс и SHA-256 оригинального изображения. scripts/import-card-images.py воспроизводит импорт. WEBP-файлы оптимизированы для экрана; оригинальные изображения остаются в Word, для точной печати нужны исходные ресурсы.

Обновление старого черновика дополняет отсутствующие картинки и заменяет стартовые изображения прототипа. Правки текста, свойств, пользовательские загрузки и сводка сохраняются. Такое обновление не считается редакционным изменением.
