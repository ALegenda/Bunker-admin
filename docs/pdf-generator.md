# Генерация PDF из HTML

Основной генератор — `backend/services/print-template.ts` и `pdf-renderer.ts`, запускаемые отдельным `backend/worker.ts`. Предыдущие Word-экспорты и замена областей PDF больше не используются API.

Все поля берутся из сохранённого снимка карточек PostgreSQL. Изображения загружаются из S3 и встраиваются в HTML; для печати создаются уменьшенные JPEG-копии, оригиналы в хранилище не меняются. Полные Segoe Print Regular и Bold встраиваются в HTML как шрифты. Внешних загрузок для документа нет.

A4, поля 15 мм, основной шрифт 10 pt. Карточки обтекают изображения, небольшие карточки переносятся целиком. Длинные описания могут занимать несколько страниц. Правила, роли, умения, мёртвые бонусы, припасы и наёмники разделены печатными разделами. Число страниц зависит от данных; совпадение с исходным PDF пиксель в пиксель не обещается.

Входной текст экранируется, пользовательский HTML/JavaScript не выполняется. Каждый запуск Chrome использует временный изолированный профиль. Готовность проверяется по стабильному завершённому PDF, затем файл открывается PDF-парсером. Это не зависит от завершения фоновых процессов Chrome. Время печати ограничено двумя минутами.

PDF, HTML и оформленный ченжлог сохраняются в S3 под идентификатором сборки. Отчёт в БД содержит ревизию, версию шаблона, число страниц, размер и SHA-256. Выпуск ссылается на уже собранный снимок: новая правка не меняет старый документ.

Проверено на полном черновике и отдельном длинном описании: русские шрифты встроены, окончание длинного текста присутствует на последней странице, правки описаний и новые карточки не блокируются старой областью PDF. Перед выпуском автор может открыть сам PDF и его печатный HTML.
